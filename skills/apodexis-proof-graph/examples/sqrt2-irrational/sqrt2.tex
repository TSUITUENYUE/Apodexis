\begin{theorem}
$\sqrt{2}$ is irrational.
\end{theorem}

\begin{proof}
Suppose for contradiction that $\sqrt{2} = p/q$ with $\gcd(p,q) = 1$.
Then $2q^2 = p^2$, so $p^2$ is even and hence $p = 2k$ is even.
Substituting, $q^2 = 2k^2$, so $q$ is even as well.
But then $2 \mid \gcd(p,q)$, contradicting $\gcd(p,q) = 1$.
Therefore $\sqrt{2}$ is irrational.
\end{proof}
